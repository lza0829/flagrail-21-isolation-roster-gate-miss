# 灰度轨

中文名：**灰度轨** · 前缀 `flagrail` · 端口 **6800 / 11800**

## 骨架

**开关版本入轨 → 分桶灰度下发 → 回读确认 → 失效/回滚互证**

皮：功能开关 / 配置灰度控制台。去皮是 **版本入轨 + 分桶下发 + 回读确认 + 命运互证**，不是配置 CRUD、不是 RBAC、不是发版审批闸。

领域：**基础设施** · 子方向：**中间件**

## 偏差隔离升（已落地）

本仓把「存在一笔偏差时如何放量」的口径**钉死为「隔离放行其余」**，不保留第二套可切换的放量路由：

- 最新回读中，所见版本与票面版本一致的「确认」进入 `确认集` / `放量集`；
- 所见版本拧花时，即使请求写了 `结果=确认`，也会改判「偏差」，禁止吞偏差当全确认；
- 偏差必须在同一事务内写入 `偏差证`、`隔离边缘` / `隔离单`，并更新同票票态；
- `POST /api/放量` 对确认边缘放量；有偏差时返回成功，同时 `隔离边缘是否非空=true`，票态为 `部分放量`；
- 纠偏回读后隔离边缘解除；再次放量才转为 `已放量`；
- 放量与新偏差并发时使用 `BEGIN IMMEDIATE` 串行化核证—隔离—票态—放量单写入，保证不会出现「部分放量但隔离集合为空」。

核证：

```bash
curl 'http://127.0.0.1:11800/api/核证?票号=票-skew-isolation'
```

返回字段包含：`确认集`、`偏差集`、`隔离集`（同名字段 `隔离集合`）、`是否可放量`、`valid`，以及
`整票可放量` / `all_green`（严格整票挡板诊断位；存在偏差时为 `false`，但本仓 `/api/放量`
采用隔离放行口径）。这里的 `valid=true` 表示偏差证、隔离集合与核证账目一致，不等于「零偏差全绿」；
零偏差请看 `偏差集=[]`、`整票可放量=true` 或 `all_green=true`。

放量与隔离实体：

```bash
curl -X POST http://127.0.0.1:11800/api/放量 \
  -H 'Content-Type: application/json' \
  -d '{"票号":"票-skew-isolation"}'
curl 'http://127.0.0.1:11800/api/隔离边缘?票号=票-skew-isolation'
```

夹具 `fixtures/偏差隔离样例.json` 是两确认、一拧花偏差，并附带 `edge-c` 的纠偏回读。
回读台页面会列出所有隔离边缘并提供核证/放量操作。

自动化断言：

```bash
python scripts/偏差断言.py
PYTHONPATH=backend pytest backend/tests -q
```
